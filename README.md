# SecureChat for Windows

A native Windows 10/11 client for **SecureChat**, the end-to-end encrypted LAN messenger. It is a Rust rewrite of the
[macOS app](https://github.com/kiritoX0914/SecureChat-macOS) and talks to the iOS and Mac apps directly over the local network. There is no server.

## Features
- 1:1 and group chats, online status, typing indicator, delivered/read receipts
- Selectable and copyable message text. **Enter** sends; **Shift+Enter** inserts a new line (safe with Chinese/Japanese IMEs)
- Reply to a message: right-click → Reply, or double-click the bubble
- Delete for me or for everyone, multi-select batch delete, clear chat, delete a chat or contact
- Photos (inline JPEG, same as iOS/Mac), files and videos of any size via chunked encrypted transfer with progress. Open them with the default app or use *Save as…*
- **Ctrl+V pastes screenshots and copied images** (with a preview), plus copied files from Explorer. You can also drag & drop files onto the window
- Profile name and photo that peers see
- Network discovery works like on the Mac: press **Scan** (known addresses, a /24 sweep and one UDP beacon) or **Connect by IP**. The app listens on TCP 47823 and remembers addresses. There is no background periodic scanning
- Data lives in `%APPDATA%\SecureChat`

## Download
Get `SecureChat-Windows-*.zip` from [Releases](../../releases), unzip it, and run `SecureChat.exe`. No installer is needed.

> **Windows Firewall:** on first start Windows asks whether SecureChat may use the network. Allow **Private networks**. Otherwise phones and Macs cannot connect to this PC (TCP 47823, UDP 47824).
> The exe is not code-signed, so SmartScreen may show "Windows protected your PC". Click *More info → Run anyway*.

## Protocol
See [docs/PROTOCOL.md](docs/PROTOCOL.md). The protocol uses X3DH (no one-time pre-keys) plus a Double Ratchet (X25519, HKDF-SHA256, HMAC-SHA256, AES-256-GCM), length-prefixed JSON envelopes, and 64 KiB AES-GCM file chunk frames.
`tests/swift_vectors.rs` checks the Rust implementation against vectors generated by the Swift code. The **Interop** workflow runs the real Swift `ChatManager` from the macOS repo against two Rust peers on a macOS runner.

## Build
```
cargo build --release --bin SecureChat      # Windows (MSVC)
cargo test  --no-default-features           # core + protocol vectors (any OS)
cargo build --release --no-default-features --bin sc-peer   # headless test peer
```
